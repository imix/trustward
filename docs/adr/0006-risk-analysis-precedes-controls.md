# Risk analysis precedes controls

Controls are added only as treatment for risks that evaluation shows are not acceptable — never speculatively. The sequence is: threats → score → evaluate against the acceptance criteria → for each open risk decide a `treatment` → add `controls:` only for the `mitigate` decisions. Adding controls first produces controls that nothing is shown to need and inverts the CRA / prEN 40000-1-2 process, where treatment is a decision driven by risk, not an input to it.
